# Writing a Book

## 2015 Q2 — [[../batches/2015-q2|batch]]

First appearance in the archive of a book project: "I'm also loving
Scrivener as I work on a book. Adding Git into play made it even
better." Practical, not aspirational-only — she's actively using tooling
for it (Scrivener for drafting, Git for version control, Bitbucket for a
private repo), and names a real anxiety about the medium: "I feel safer
backing up my stuff continuously. Don't trust technology, even if I like
some of it." No content, topic, or timeline given yet — worth watching
what the book turns out to be about and whether it connects to her
testing work or is separate from it.
