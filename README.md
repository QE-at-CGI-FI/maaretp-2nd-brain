# maaretp-2nd-brain
Building up an LLM wiki on @maaretp in public.

- `raw/` — immutable source archives (Twitter, Mastodon)
- `wiki/testing/`, `wiki/personal/` — the two wikis, maintained by an LLM agent
- `tools/` — scripts to merge/extract the raw archives for ingestion
- `CLAUDE.md` — the schema/workflow the agent follows
- `LLM-wiki-idea.md` — the general pattern this repo instantiates

Open the repo root in Obsidian to browse the wikis; use Claude Code (or
another agent following `CLAUDE.md`) to ingest new batches and answer
questions against them.
